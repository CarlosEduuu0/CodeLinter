# CodeLinter

Reconhecedor de trechos de código-fonte com **Expressões Regulares** e **AFNε equivalentes**, feito para a disciplina de Linguagens Formais e Autômatos (CESUPA).

> Documentação completa em construção (iteração q10).

## Como executar

> No Windows, se `python` não funcionar, use `py` no lugar.

```bash
pip install -r src/requirements.txt
cd src
python main.py
```

## Como rodar os testes

Na raiz do projeto:

```bash
python -m pytest
```
